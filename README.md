## Task Manager Backend

โปรเจกต์สำหรับฝึกพัฒนา REST API ด้วย Node.js และ Express

* CRUD: GET, POST, PATCH, DELETE
* REST API และ HTTP Status Codes
* แยกโครงสร้าง Route / Controller / Store
* Validation และ Error Handling พื้นฐาน
* ใช้ Async/Await
* เริ่มจากเก็บข้อมูลด้วย JSON
* ย้าย Database จาก JSON ไป MySQL
* ใช้ `mysql2`
* ใช้ SQL: SELECT, INSERT, UPDATE, DELETE
* ใช้ Parameterized Query (`?`)
* ใช้ `AUTO_INCREMENT` และ `insertId`

### Tech Stack

Node.js • Express • MySQL • mysql2
